# UA Web Finder 1.4.0

Безкоштовна локальна Windows-програма для пошуку різних типів сайтів, попереднього визначення CMS та збору контактів, які власники опублікували у відкритому доступі. Це не лише пошук інтернет-магазинів і не обмежується Україною.

## Що змінилося в 1.4.0
- Нове джерело «Список доменів зони (Majestic)»: безкоштовний список ~1 млн популярних доменів, з якого береться потрібна зона (.ua). Це надійніше за пошуковики, які блокують автоматичні запити. Далі кожен домен перевіряється по коду.
- Перевірка в 8 потоків, кнопка «Зупинити», пропуск доменів, які вже перевірялись.
- WooCommerce підтверджується за розміткою або через публічний Store API магазину (`/wp-json/wc/store/v1/products`).
- Суворіше відбір: «Україна» = домен .ua, або телефон +380, або «грн/₴» (одна лише українська мова не рахується); якщо вибрано мову, а сайт її не підтверджує, його відсіює.

## Що змінилося в 1.3.2
- З пошукової видачі беруться лише органічні результати (раніше — всі посилання сторінки, звідси Яндекс, chatgpt.com тощо).
- Якщо вибрано лише «Україна», кандидати поза зоною `.ua` відкидаються.
- Список знайдених доменів виводиться в журнал.
- Додано запити за типовими фразами розмітки WooCommerce; порожні категорії підставляють залежно від вибраних мов.

## Що змінилося в 1.3.1
- Раніше фільтри «CMS / країна / мова» впливали лише на текст пошукових запитів, а знайдені домени зберігались без жодної перевірки. Тепер на кроці «Перевірити контакти» кожен сайт перевіряється на відповідність платформі, країні, мові та типу, а невідповідні відсіюються (з причиною в журналі). Вимкнути можна галочкою «Зберігати лише сайти, що відповідають фільтрам».
- Регіональний фільтр `site:.ua` тепер додається до всіх запитів, а не до перших 8.
- Мова впливає на запити (фрази «Додати в кошик» / «Add to cart» / «В корзину»); додано мову «Російська» та вибір типу сайту.
- Черга доменів більше не накопичує результати попередніх пошуків.
- Новинні сайти більше не вважаються магазинами через слова «купити»/«ціна»; WooCommerce/WordPress визначаються за розміткою, а не за словом у тексті.
- Додано CS-Cart, збір `mailto:`/`tel:`, пошук контактів на сторінці «Контакти», кнопку «Очистити базу».

## Можливості
- Пошук із платформними запитами для WooCommerce, WordPress і WordPress + HivePress. HivePress розпізнається окремо від звичайного WordPress.
- Пошук через вибрані джерела: DuckDuckGo, Bing, Mojeek; Google доступний як додаткове джерело.
- Об'єднання результатів і видалення повторів доменів.
- Імпорт власного списку доменів TXT/CSV без використання пошуковиків.
- Перевірка сайтів, попереднє визначення платформи, збір опублікованих email/телефонів/Viber.
- Локальна база та експорт CSV для Excel.
- Пошукові категорії, теги, географічні підказки, платформи та ліміт доменів.

## Збирання EXE у Windows
1. Встановіть Node.js LTS з офіційного сайту https://nodejs.org/.
2. Розпакуйте архів у звичайну папку, наприклад `C:\UA-Web-Finder`.
3. Двічі клацніть `build.bat` і дочекайтеся повідомлення про завершення.
4. Готовий портативний EXE має з'явитися в папці `dist`.

Якщо Windows Defender або браузер попереджає про архів чи EXE, не вимикайте захист. Перевірте файл засобом «Безпека Windows» і переконайтеся, що завантажили вихідний код. Цей архів містить вихідний код, а не готовий EXE.

## Обмеження
- Пошукові сайти можуть змінювати HTML, вимагати CAPTCHA, повертати HTTP 403/429 або обмежувати автоматичні запити. Якщо одне джерело блокує доступ, спробуйте вимкнути його і залишити інші; це не гарантує результатів.
- Google може частіше показувати перевірки. Bing/Mojeek/DuckDuckGo також можуть бути недоступні залежно від мережі та регіону.
- Вибір країни, мови й платформи впливає на запити, але пошукова видача все одно може містити нерелевантні сайти. Платформа й тип сайту визначаються за евристиками; результати потрібно перевіряти. HivePress є плагіном WordPress і позначається як «WordPress + HivePress».
- Збір контактів обмежений публічно доступними сторінками; не обходьте CAPTCHA, авторизацію або технічні блокування. Дотримуйтеся умов сайтів і законодавства про персональні дані та електронний маркетинг. Наявність публічного контакту не означає згоду на розсилку.
- Повний запуск і збірка мають перевірятися на вашому Windows-комп'ютері.
